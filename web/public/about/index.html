Designed for self-hosting

Run the application with Docker or Portainer and keep storage, accounts, and processing inside the deployment you control.

  • Restricted Worker execution and managed converter versions
  • Non-destructive originals, results, and document page workflows
  • Capabilities depend on the profiles and engines you install
