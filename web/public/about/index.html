Self-hosting quick start

Run the workspace where your files live.

On a Docker host, the repository installer creates the initial environment and starts the existing Compose stack. Keep the generated secrets private.

git clone https://github.com/Timisah/101conv.git
cd 101conv
./scripts/install.sh
  • Open http://<docker-host>:5656 and finish first-run setup.
  • Keep .env private; it contains bootstrap and database credentials.
  • Review the catalog and install only the engines and profiles your deployment needs.
Read the installation and deployment notes on GitHub

Verified catalog

Capabilities you can install and review.

The official catalog currently covers these tested paths. A deployment only exposes the engines and profiles its administrator installs.

Images

Sources: JPG/JPEG, PNG, WebP, TIFF, BMP, GIF, and AVIF. FFmpeg image profiles target those formats; JPEG XL profiles add JPG/JPEG, PNG/APNG, GIF, and JXL paths.

Image profile details

Audio and video

Sources: common MP4/MKV/MOV/AVI/WebM-family video and MP3/AAC/M4A/OGG/OPUS/WAV/FLAC/WMA/AMR audio containers, with target-specific conversion and compression profiles.

Media fidelity limits

Documents

Office: DOCX, DOC, ODT, XLSX, XLS, ODS, PPTX, PPT, ODP, RTF, and TXT to PDF. PDF: one selected page to PNG/JPG or bounded text extraction.

Document support details

Supported formats and fidelity depend on the installed catalog, engine revision, and deployment architecture. The catalog and repository documentation are the source of truth; no universal format or fidelity guarantee is implied.
